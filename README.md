## ✨ About the Project

What if a classic childhood game got a futuristic makeover? 🚀

This project brings Rock Paper Scissors to life with an interactive gaming experience, a computer opponent, engaging visuals, and fun victory celebrations.

🌐 **[Play the Game Live](https://rock-paper-scissors-rust-seven.vercel.app/)**

## 🚀 Features

- 🎮 Interactive Rock, Paper, and Scissors gameplay
- 🤖 Computer opponent
- 👤 Character selection
- 🏆 Score tracking
- 🎉 Victory celebrations and sound effects
- 🌌 Neon-inspired interface with custom backgrounds
- 🌐 Live web deployment using Vercel

## 🕹️ Game Rules

| Move | Beats |
|---|---|
| 🪨 Rock | ✂️ Scissors |
| 📄 Paper | 🪨 Rock |
| ✂️ Scissors | 📄 Paper |

🤝 Matching moves result in a draw!
